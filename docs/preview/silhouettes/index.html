Decorative Silhouettes

Industry-specific SVG silhouettes for section backgrounds. Use the Silhouette component with a type prop. Pick one that matches the client's business.

type="trees" Landscaping, tree service, outdoor contractors
type="cityscape" General contractors, commercial, urban services
type="roofline" Roofing, home improvement, remodeling
type="tools" Plumbing, electrical, HVAC, handyman
type="waves" Plumbing, pool service, marine, pressure washing
type="mountains" General outdoor, adventure, rural contractors

On Dark Backgrounds

Same silhouettes work on dark sections too — just change the color class.

type="trees" class="text-white/10"
type="cityscape" class="text-white/10"
type="roofline" class="text-white/10"
type="tools" class="text-white/10"
type="waves" class="text-white/10"
type="mountains" class="text-white/10"
